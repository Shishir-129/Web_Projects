# Web_Projects 🌐

## Overview
**Web_Projects** is a collection of websites and web applications that I have built to practice and demonstrate my skills in modern web development.  
Each project is organized in its own folder and focuses on clean UI, responsive design, and practical functionality.
Some of these sites are made for fun purpose where I use UIs and themes I like myself, while others are made for learning purposes where I try to implement new technologies and concepts.

## Technologies & Tools
- **HTML5**
- **CSS3** (Flexbox, Grid, Animations)
- **JavaScript (ES6+)**
- **React.js** (for selected projects)
- **Django** (for backend-based projects)
- **Node.js & Express** (for backend-based projects)
- **MongoDB** (where applicable)
- **Git & GitHub** for version control
